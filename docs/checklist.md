# ブラウザでの確認項目

確認したら ☐ を ☑ に書き換えます。当てはまらない項目は「—」にします。

- **Safari（Mac）**：先に「設定 → 詳細 → Tab キーを押したときに Web ページ上の各項目を強調表示」をオンにする（オフのままだと、Tab キーでボタンに移動できない）
- **テスト用の音**：手元で生成した `sample-track.wav`（30秒のサイン波）を使うと、曲名にアーティスト名が出ない

## レコードの回転

| 確認項目 | Chrome | Firefox | Safari | iPhone |
|---|---|---|---|---|
| 再生すると回り、停止するとその角度のまま止まる | ☐ | ☐ | ☐ | ☐ |
| 33回転で1周約1.8秒、45回転で約1.33秒、スクリューで約2.43秒 | ☐ | ☐ | ☐ | ☐ |
| 再生中に回転数やピッチを変えても、角度が飛ばない | ☐ | ☐ | ☐ | ☐ |
| 「動きを減らす」をオンにすると、再生中でも止まる | ☐ | ☐ | ☐ | ☐ |
| 「動きを減らす」をオフに戻すと、再生中なら回り出す | ☐ | ☐ | ☐ | ☐ |

「動きを減らす」の場所：Mac は「システム設定 → アクセシビリティ → ディスプレイ → 視差効果を減らす」、iPhone は「設定 → アクセシビリティ → 動作 → 視差効果を減らす」。
